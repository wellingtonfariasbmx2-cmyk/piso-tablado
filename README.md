# Piso Tablado

Sistema quantitativo de tablado, pé, travessa, cano em X e guarda-corpo. Digital Produções e Eventos.

## Código

https://github.com/wellingtonfariasbmx2-cmyk/piso-tablado

## Instalar no Windows

1. Baixe [Instalar-Piso-Tablado.exe](https://github.com/wellingtonfariasbmx2-cmyk/piso-tablado/releases/download/v1.0.0/Instalar-Piso-Tablado.exe).
2. Abra o arquivo, escolha a pasta e conclua.
3. O atalho **Piso Tablado** aparece na área de trabalho e no menu Iniciar.

O instalador não tem assinatura digital. Se o Windows mostrar a tela azul do SmartScreen, clique em **Mais informações** e depois em **Executar mesmo assim**.

## Link para outras pessoas

Depois de ligar o GitHub Pages em Settings, Pages, Source: GitHub Actions, o sistema abre em:

https://wellingtonfariasbmx2-cmyk.github.io/piso-tablado/

Quem receber esse endereço usa o piso no navegador, sem instalar. Os pisos salvos ficam naquele computador, naquele navegador.

# Piso Tablado

Sistema quantitativo de tablado, pé, travessa, cano em X e guarda-corpo. Digital Produções e Eventos.

## Usar pelo link

Qualquer pessoa abre este endereço, sem instalar nada:

https://cdn.jsdelivr.net/gh/wellingtonfariasbmx2-cmyk/piso-tablado@main/site/index.html

Os pisos salvos ficam neste computador, neste navegador. Mande o mesmo link para quem for montar o piso.

Código do sistema: https://github.com/wellingtonfariasbmx2-cmyk/piso-tablado

## Instalar no Windows

1. Baixe `Instalar-Piso-Tablado.exe` na [página de releases](https://github.com/wellingtonfariasbmx2-cmyk/piso-tablado/releases).
2. Abra o arquivo, escolha a pasta e conclua.
3. O atalho **Piso Tablado** aparece na área de trabalho e no menu Iniciar.

O instalador não tem assinatura digital. Se o Windows mostrar a tela azul do SmartScreen, clique em **Mais informações** e depois em **Executar mesmo assim**.
